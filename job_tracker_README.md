# История вакансий и ежедневный запуск

Эти файлы дополняют твой существующий `job_filter_mcp.py`. Его ключевые слова,
зарплата и город продолжают использоваться. Файл с твоими настройками не заменяется.

## Установка в твою папку

1. Положи `job_tracker.py` и `install_job_schedule.ps1` рядом с `job_filter_mcp.py`.
   Твоя папка: `C:\Users\FlyUp Travel\Desktop\Python Biznesa datu analze`.
2. Закрой CSV-файлы в Excel, чтобы программа могла обновить их.
3. Открой эту папку в VS Code. В терминале PowerShell выполни:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_job_schedule.ps1
```

Скрипт сначала проверит Python, выполнит загрузку и создаст историю, затем
зарегистрирует задание `LatviaVacanciesMorning` на 09:00 ежедневно по местному
времени компьютера. Успешная установка заканчивается строкой
`READY: LatviaVacanciesMorning` и временем следующего запуска.

Параметр `-ExecutionPolicy Bypass` действует только для запущенного процесса
PowerShell; политика компьютера постоянно не изменяется. Скрипт можно заранее
открыть в VS Code и прочитать.

Используется твоя обычная учётная запись Windows, без сохранения пароля.
Нужны включённый компьютер, интернет и вход в Windows. Блокировка экрана допустима.
Если время пропущено, включено выполнение при следующей доступности.
Выключенный компьютер программа не включает. Настроены до трёх повторов после
ошибки с интервалом 10 минут; одновременные запуски не накладываются друг на друга.

## Что создаётся

| Файл | Содержание |
| --- | --- |
| `vacancies_live.csv` | Вся текущая подборка по твоим условиям |
| `vacancies_new.csv` | Объявления, впервые найденные для тебя сегодня |
| `vacancies_history.csv` | Все когда-либо записанные ID и даты наблюдения программой |
| `vacancies_changes.csv` | Изменения зарплаты, срока, других полей и присутствия в подборке за сегодня |
| `vacancies_live_report.txt` | Краткий отчёт о последнем успешном запросе |
| `vacancies_history.sqlite3` | Основная база истории; сохраняй её при переносе проекта |
| `snapshots` | Архив каждого успешного запроса и его новых объявлений |
| `logs` | Журналы запусков и ошибок |
| `vacancies.lock` | Служебный файл для защиты от одновременных запусков |

«Новые» означает новые для твоей истории. При расширении фильтров туда могут
попасть объявления, опубликованные давно. Это не означает «опубликованы сегодня».

Если при первом запуске уже есть `vacancies_live.csv`, его строки становятся
исходным известным списком. Если такого файла нет, исходным списком становится
первая выгрузка, а файл новых будет пустым до появления новых ID.

Повторный запуск сегодня сохраняет все найденные сегодня новые ID в
`vacancies_new.csv`. На следующий день этот файл относится к новому дню;
вчерашние данные остаются в истории и архиве. Поле `in_latest_selection`
показывает `yes` / `no`: находится ли объявление в последней подборке.
`no` не означает подтверждённое закрытие вакансии.

Сравнение идёт по ID объявления CV.lv. Объявления одной позиции на двух языках
с разными ID остаются отдельными записями. Зарплата сравнивается по нижней
границе; остальные условия берутся из исходной программы.

Если сервер вернул неполную выдачу из-за `MAX_RESULTS`, история не обновляется:
увеличь этот параметр в `job_filter_mcp.py` (до 500) или уточни фильтры.
Ошибка сети не помечает старые объявления закрытыми и не очищает историю.
Если сохранению CSV помешал Excel, данные запроса остаются в базе и будут
повторно экспортированы при следующем запуске.

## Управление

Запустить вручную с учётом истории:

```powershell
uv run .\job_tracker.py
```

Изменить время на 10:30:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_job_schedule.ps1 -At 10:30
```

Посмотреть состояние задания и результат последнего запуска:

```powershell
Get-ScheduledTask -TaskName LatviaVacanciesMorning
Get-ScheduledTaskInfo -TaskName LatviaVacanciesMorning
```

`LastTaskResult = 0` после выполнения означает успешное завершение процесса.
Перед первым запуском в Планировщике результат может обозначать «ещё не запускалось».
Если программа уже работает, второй ручной запуск будет пропущен.

Отключить расписание:

```powershell
Disable-ScheduledTask -TaskName LatviaVacanciesMorning
```

Включить снова:

```powershell
Enable-ScheduledTask -TaskName LatviaVacanciesMorning
```

После переноса папки повтори установку с новым местом файлов. Если установщик
сообщит, что имя задания занято другой папкой, открой Планировщик заданий,
проверь путь старого задания и удали именно старое `LatviaVacanciesMorning`
перед регистрацией в новом месте. Другие задания установщик не изменяет.
